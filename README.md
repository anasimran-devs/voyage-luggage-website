# 🧳 Voyage — Luggage E-Commerce Website

A modern and responsive luggage e-commerce website designed with a clean and elegant user interface.

Voyage provides a multi-page shopping experience for browsing luggage products, viewing product details, exploring brands, managing the cart, and contacting the store.

## 🚀 Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/anasimran-devs/voyage-luggage-website.git
```

### 2. Open the project

```bash
cd voyage-luggage-website
```

### 3. Run the website

Open `index.html` in your browser.

For the best development experience, you can use VS Code with Live Server.
